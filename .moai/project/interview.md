# Project Interview

## Round 1: Vision
Question: 이 프로젝트는 무엇을 만드는 건가요? 누가 사용하나요?
Answer: 마크다운 생성 도구 — 텍스트나 데이터를 마크다운(.md) 문서로 자동 변환/생성해주는 도구.

## Round 2: Technology
Question: 이 마크다운 생성 도구는 주로 어떤 기술로 만들 예정인가요?
Answer: Python

## Round 3: Scope
Question: 마크다운 생성 도구의 핵심 기능과 범위는 어디까지인가요?
Answer: 템플릿 기반 문서 자동 생성 — 입력값(데이터, 변수)을 받아서 정해진 템플릿에 맞춰 .md 파일을 자동으로 생성. 보고서, 회의록, 문서 양식화에 적합.
