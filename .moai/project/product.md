# 프로젝트 개요 (product.md)

> 본 문서는 그린필드(신규) 프로젝트 문서입니다. 아직 소스 코드가 존재하지 않으며, 아래 내용은 `.moai/project/interview.md`의 인터뷰 결과를 바탕으로 한 **계획된 제품 방향**입니다.

## 프로젝트 이름

**markdown_creat** (마크다운 생성 도구, 가칭)

## 프로젝트 설명

텍스트나 데이터를 마크다운(.md) 문서로 자동 변환/생성해주는 Python 기반 도구입니다. 핵심 아이디어는 **템플릿 기반 자동 문서 생성**으로, 사용자가 입력값(데이터, 변수)을 제공하면 미리 정의된 템플릿에 맞춰 표준화된 `.md` 파일을 자동으로 만들어줍니다. 매번 수작업으로 문서 형식을 맞추는 반복 작업을 줄이고, 조직 내 문서 포맷의 일관성을 확보하는 것이 목표입니다.

## 타겟 사용자

- 정기적으로 보고서나 회의록을 작성해야 하는 실무자 (기획자, PM, 팀 리더 등)
- 표준화된 문서 양식(보고서, 회의록, 체크리스트 등)을 반복적으로 생성해야 하는 조직/팀
- 마크다운 기반 문서 관리 워크플로우(정적 사이트, 위키, Git 저장소 등)를 사용하는 개발자 및 기술 문서 작성자
- 데이터/설정값을 바탕으로 문서를 자동화하고 싶은 개인 사용자

## 핵심 기능 (계획된 범위)

아래 기능은 아직 구현되지 않은 **의도된 스코프**이며, 향후 SPEC 및 구현 단계에서 구체화될 예정입니다.

1. **템플릿 정의 기능**: 사용자가 원하는 문서 구조(보고서, 회의록 등)를 템플릿 형태로 정의할 수 있는 기능
2. **입력값 바인딩**: 데이터/변수(딕셔너리, JSON, YAML 등)를 템플릿에 매핑하여 값을 채워 넣는 기능
3. **마크다운 파일 자동 생성**: 템플릿 + 입력값을 조합해 `.md` 파일을 생성하고 지정된 경로에 저장하는 기능
4. **표준 문서 양식 지원**: 보고서, 회의록 등 자주 사용되는 문서 유형에 대한 기본 템플릿 제공(예정)
5. **CLI 인터페이스**: 커맨드라인에서 템플릿과 데이터를 지정해 문서를 생성할 수 있는 실행 방식 (예정)

## 사용 사례 (Use Cases)

- **정기 보고서 생성**: 주간/월간 보고서처럼 형식이 고정된 문서를 데이터만 바꿔가며 반복 생성
- **회의록 자동화**: 회의 안건, 참석자, 결정사항 등을 입력하면 정해진 회의록 양식의 `.md` 파일로 변환
- **문서 양식 표준화**: 팀/조직 내에서 문서 포맷을 통일하고, 신규 문서 작성 시 템플릿을 재사용
- **문서 파이프라인 연동**: 생성된 `.md` 파일을 정적 사이트 생성기(예: Nextra, MkDocs 등)나 Git 기반 문서 저장소에 연계
